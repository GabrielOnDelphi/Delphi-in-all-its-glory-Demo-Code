# Code examples
for the "[Delphi, in all its glory](https://GabrielMoraru.com/publications-citations/)" book (2023).  
Get the book in printed or electronic format.   

The Release builds of the demos need no Autopilot; the Debug builds also use the optional [Autopilot for Delphi](https://gabrielmoraru.com/my-delphi-code/autopilot-for-delphi/) bridge, which lets an AI assistant drive the running app (some demos also need FastMM4 or [LightSaber](https://github.com/GabrielOnDelphi/Delphi-LightSaber)).
